# R3 hand list: closed to scripts, for the user's browser

Save each file into `Projects/Venice Biennale Pavilions/Inbox/` under the name given.

## H1. Institut français IF PROG (login) - call dossiers for the French pavilion
- http://ifprog.institutfrancais.com/fr/login : the calls for projects (Architecture 2016, 2018, 2020, 2023, 2025;
  Art) are filed here; the call dossiers usually include the pavilion's technical plans. Login required: not used by
  the route. If the user has access, save any "plans du pavillon" / "dossier technique" PDF or DWG as
  `fr_IF_dossier-technique_<year>.<ext>`.

## H2. French Embassy in Italy - tenders page (robots.txt closed to scripts)
- https://it.diplomatie.gouv.fr/it/presence-francaise/offerte-di-lavoro-e-bandi-di-gara (also the French version under
  /fr/presence-francaise/...). Look for the 2024-2026 tender for the renovation of the French pavilion in the Giardini
  ("Padiglione francese", "Pavillon français de Venise", "lavori di ristrutturazione/rinnovo"). Save the notice and
  every annex with drawings (progetto, elaborati grafici, DWG/PDF) as `fr_ambassade_gara_<name>.<ext>`.
